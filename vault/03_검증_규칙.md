# 검증 3단계

1. **사건 JSON 보존 (FORM_SIMILARITY)** — 원 차트 → JSON → 다시 그림.
   픽셀 일치가 아니라: 모양 상관, 뼈대 순서(U/D) 일치, 평균 오차. 낮은 사건은 주소와 이유.
2. **그룹 JSON (형태 범위)** — 소속 사건을 하나씩 빼고 잰 자기 그룹 거리 분포 = `self_fit`.
   자기 자신이 들어간 JSON으로 재면 100%가 공짜로 나오므로 금지.
3. **q-by-q 다시 흘리기** — ZC1 마감부터 한 봉씩, 그 시각까지의 관측만.
   - 성공 = 최종 L/H 봉 마감 + 12개 5분봉 안에 자기 그룹이 **1등** (보조: 3등 안), 이후 유지
   - 같이 보고: 그때 fit ≥ 0.5 인 그룹 수 (28개 다 맞다고 하면 실패)
   - 엄격판: 그 시각 뒤에 끝난 사건을 기억에서 뺀 순위
   - 목표 100%. 실패 사건은 숨기지 않고 주소 + 이유(두 그룹 사이 / 덜 그려짐 / 맥락 다름)

실행: `python -m twin.pipeline replay "$TWIN_OHLCV" result.csv` · 에이전트 `replay-validator` · MCP `replay`
